# Brain Repo List

Inventory for the Puspa Brain phase. Sources: survey 1 (`repo-reuse-puspa-2026-11-17.md`, 17 Nov 2026), survey 2 (`chassis-tambahan-2026-11-17.md`, 17 Nov 2026), the product brief (`brief-puspa-lengkap-2026-11-17.md`), the revision 7 MVP definition (`definisi-mvp-puspa-2026-11-17-revisi-7.md`), and Nero's direct order (hermes-agent, opencode, claude code, plus independent mature finds). Existing Puspa code was checked in `puspa/` and `tests/` and in `REUSE.md` and `docs/reuse.md`.

Rules followed here: study the pattern or idea, then rewrite it as Puspa's own code. Never copy code verbatim. Never use code licensed GPL, AGPL, SSPL, PolyForm, CC BY-NC, or a custom non-OSI license. Never create a GitHub fork of any repo. Dependencies only through pip with a compatible license (MIT, Apache-2.0, BSD). This file changes nothing in revision 7.

## How to read this list

- **Origin** tells where a row came from: `survey1`, `survey2`, `survey-mention` (named inside a survey but not in a main heading), `nero` (Nero's direct order), `brief` (named in the brief or revision 7), `independent` (found by this inventory through public web search, 18 Nov 2026).
- **Moat / core** is one or two specific sentences: what the system does that is hard to copy, not a slogan.
- **License + status** is taken from the surveys where available (stars and dates as of 17 Nov 2026) or from public web search where marked. `DO NOT USE` means the code must not be used in Puspa; the idea or pattern may still be studied and rewritten.
- **In Puspa** names the exact file when the pattern is already implemented, or says `USED AS DEPENDENCY` or `PATTERN ONLY`. Empty means not present.
- **Plan / out-of-scope reason** names the Puspa module to build, or gives the one-line out-of-scope reason.
- Stars are a snapshot, not a verdict. `Not verified` means this inventory did not check that fact; do not cite it as established.
- No em dash is used in this file, per repo convention.
